# ==== comments ====
cmt 0x10100 Game driver: init (Malloc buffers, install REFRESH as VBL) then attract/gameplay loops. Never returns.
cmt 0x1110e game_update: input, integrate throttle->speed, steering->road_curve, off-road/collision, stream course, run event script, checkpoints/score.
cmt 0x11aa2 Course-event jump table: 129 word-offset entries; handler = 0x11aa2 + entry.
cmt 0x13144 Object-type sprite dispatch jump table (indexed by object type 0..63).
cmt 0x10620 RLE graphics unpacker: 0x1234=zero-run, 0x5678=ff-run, 0x1234^3=end; then 4-plane interleave.
cmt 0x1087e draw_object: scale+position a roadside object from road_width_tbl, dispatch to 8 blit variants.
cmt 0x152ac draw_buggy: player car body + wheel/shadow sub-sprites, offset by crash/skid state.
cmt 0x1b394 Sound-command jump table (note-stream commands >= 0x80).
