# ==== comments ====
cmt 0x10000 Entry: init_system, init_game, title_screen, init_video; then infinite main loop of per-frame subsystems.
cmt 0x10080 init_system: check resolution (halt if mono), install screen/vbl vectors, save+mask conterm (0x484).
cmt 0x105f0 init_game: copy state templates into object_table, relocate ptrs by screen_base, set screen geometry + back buffer.
cmt 0x10aae title_screen: title bitmap + palette cycle + '1'/'2' player-select with attract timeout (README HW-detect screen).
cmt 0x12014 update_objects: per-object physics + AI (flap/gravity/direction, home toward players) — the buzzard/enemy movement.
cmt 0x12606 animate_objects: object lifecycle — egg-hatch/spawn state machine, animation-frame advance, screen-position calc.
cmt 0x12cc2 render_objects: walk object_table, advance flap-animation frame (0-4), draw each object sprite.
cmt 0x13842 collision_check: test each object vs platform/object boxes (test_overlap), flag hits (0x4000).
cmt 0x14ada spawn_wave: enemy/egg spawn scheduler; ramps difficulty by halving spawn_interval.
cmt 0x1783c wave_manager: game-phase/round transitions; spawns wave-announcement messages; next-wave setup.
cmt 0x146f6 lava_troll: from wave 4+, the lava hand reaches up to grab objects over the pit.
cmt 0x177a2 blit_sprite: shifted masked sprite draw (AND mask + OR data), 0x50-word row stride.
