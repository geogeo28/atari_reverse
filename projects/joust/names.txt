# Joust (Atari ST, Williams/Atari; Gamex release). Depacked from JOUSTS.CTE via
# tools/depack_gamex.py. Ghidra addresses = image offset + 0x10000. No DRI symbols.
# 75/75 functions named. "# ctx" = inferred from behaviour/context (refinable);
# untagged = confirmed by reading the body (decomp.c + 68000 disassembly).
#
# NOTE: many names here were corrected after reading the asm — the XBIOS opcode
# table in tools/prg_dis.py and tools/ghidra_scripts/AtariOsTrapAnnotate.java WAS
# wrong (0x20 is Dosound, not Supexec; 0x1c Giaccess and 0x19 Ikbdws were missing;
# 0x1f/0x21/0x28/0x2a were decimal-as-hex mistakes). That mislabelled the whole
# sound driver as palette/keyboard/graphics code. See the cmt lines below.
# Both tables are CORRECT as of this commit — trust the annotations again; the
# lesson is recorded in docs/tos-os-calls.md's trap-table warning.

# ==== comments: top level ====
cmt 0x10000 Entry: init_system, init_game, title_screen, init_video; then an infinite per-frame loop. hiscore_key_input's RETURN handler jumps back to 0x10006 (init_game) to restart the game.
cmt 0x10080 init_system: bail out if Getrez()==2 (mono), install the IKBD mouse/joystick vectors via Kbdvbase (saving the old ones in saved_mousevec/saved_joyvec), save+mask conterm (0x484), record Physbase in screen_base.
cmt 0x105f0 init_game: copy the state templates (0x114f8 -> players_alive.., 0x1145c -> object_table), relocate the two score-text pointers by screen_base, clear the message/pterodactyl/effect tables, set geometry (ground_x0/x1 = 0..0x13f) and playfield_bottom = screen_base+32000.
cmt 0x10aae title_screen: draw the title bitmap (0x23aae..0x2b7ae) to screen_base, three draw_string lines, cycle_palette + rotate 6 palette entries, then Bconin: '1'/'2' select 1P/2P (players_alive + two_player_mode); a 400-tick timeout falls through to the attract loop.
cmt 0x104b2 init_video: fill_screen, draw the HUD separator rows, then draw_platforms + score/lives redraw + snd_tone_sweep (the start-of-game sound).

# ==== comments: object model ====
cmt 0x10f36 object_table: 14 slots x 0x4e bytes, ending at effect_table. Slot 0 = player 1, slot 1 = player 2 (0x10f84), slots 2..13 = enemies (enemy_objects, 0x10fd2). Fields: +0 flags.w, +2 x.w, +4 y.w, +6 vx.w, +8 vy.w, +0xa anim timer.b, +0xb step timer.b, +0xc target vx.w, +0xe flap frame.w, +0x10/+0x12 prev x/y, +0x14 prev dst.l, +0x18 prev src.l, +0x1c rows.b, +0x1d shift.b, +0x1e EGG state.b, +0x20/+0x22 egg x/y, +0x24/+0x26 egg dx/dy, +0x28/+0x29 egg timers, +0x2a egg dst.l, +0x2e egg src.l, +0x32 egg rows.b, +0x33 egg shift.b, +0x35 egg-chain counter, +0x36 score text ptr.l, +0x3a score text shift.w, +0x3c..+0x44 ASCII score digits, +0x49/+0x4b AI timers, +0x4c lives.
cmt 0x12014 update_objects flags word (object+0): bits0-1 = enemy type 1/2/3 (each has its own speed: speed_type1/2/3), bit2 = is a player, bit4 = grabbed by the lava troll, bit6/bit11 = flapping, bit7 = awaiting respawn, bit8 = falling into the lava, bit9 = standing on a platform, bit13 = dead/removed, bit14 = bumped a platform edge, bit15 = facing right.
cmt 0x113ba pterodactyl_table: 4 slots x 0x20 bytes. Fields: +0 flags.w (bit0 = just spawned, bit2 = moving right, bit5 = dying), +2 dst.l, +6 src.l, +0xc x.w, +0xe y.w, +0x10 x speed.w, +0x12 y speed.w, +0x16 dst offset.w, +0x1a anim.w, +0x1c..0x1f direction/dwell timers.
cmt 0x117b4 platform_table: 8 records x 8 bytes {y0.w, y1.w, x0.w, x1.w} — the landable boxes, gated by platform_present[i] (0x10cfa, one byte per platform: 0 = absent this wave, >0 = needs a redraw, -1 = drawn).
cmt 0x117f4 platform_edge_table: 28 records x 12 bytes {y0,y1,x0,x1, x-push.b, y-push.b, platform index.w} — the bump boxes used by render_object_body's bit14 branch to push an object off a platform edge and force a platform redraw.
cmt 0x119d4 platform_sprites: 8 records x 16 bytes {ptr to platform_present[i], rows.w, cols.w, src.l, dst offset.l} — the platform bitmaps, OR-blitted by draw_platforms and used as the pixel-collision surface by collision_check/test_overlap.
cmt 0x11964 spawn_points: 5 longs per record, terminated at 0x119b4 {in-use.b, y0.w, y1.w, x0.w, x1.w, y.w, x.w}. render_object_body walks them with spawn_point_cursor looking for one clear of every object before respawning a rider there.
cmt 0x10e16 message_table: records of 12 bytes {kind.b, timer.b, colour.b, shift.b, screen ptr.l, string ptr.l}, running up to object_table. find_free_message returns the first slot with kind==0 in a0.

# ==== comments: verified renames (evidence) ====
cmt 0x10a56 play_sound(index.w @4): if index <= snd_priority, store it and XBIOS Dosound(sound_table[index]) — trap #14 opcode 0x20 is Dosound (38/0x26 is Supexec). Lower index = higher priority. Was mis-named set_color_lvl from a wrong XBIOS table.
cmt 0x10a8a snd_poll_done: XBIOS Giaccess(0, 7) reads the YM2149 mixer; when all six tone+noise enables are off (0x3f) the sound has finished, so snd_priority is released to 0x10 (idle). Called once per frame from _start. Was mis-named read_key_flag.
cmt 0x1096e snd_tone_sweep: writes YM2149 registers 0,1,2,3,7,8,9,0xa via XBIOS Giaccess in a nested loop that steps snd_sweep_pitch down by 2 and snd_sweep_volume down by 1 — a descending two-channel sweep played at the end of init_video. Was mis-named init_gfx.
cmt 0x11d9a read_joysticks: Ikbdws(0, ikbd_cmd_joyread) sends the IKBD 'interrogate joysticks' command (0x16), spins until the IKBD handler stores the reply in ikbd_packet, then calls control_player with a0=player1/d0=joystick1 and a0=player2/d0=joystick0. Nothing here waits for vblank — was mis-named wait_vsync.
cmt 0x11dd6 control_player(a0=player object, d0.b=joystick byte): bit7 fire = flap, bit3 = right (vx +4), bit2 = left (vx -4). With no players left, fire restarts the game (game_over_flag, check_highscore, init_game, init_video and back into the main loop).
cmt 0x11c24 poll_quit_key: Bconstat/Bconin; only Ctrl-C (3) acts — Dosound(silence), write hiscore_name to HIGH.SCO (Fopen/Fcreate + Fwrite 0x1a bytes + Fclose) if hiscore_dirty, restore conterm/Setscreen/IKBD vectors/palette, Pterm. Every other key falls through the 0x11d58 table and returns.
cmt 0x105c2 rng_advance: the pseudo-random source is a pointer (rng_ptr) walking the program image 2 bytes at a time and wrapping at 0x17832; callers read words at *rng_ptr for randomness (spawn side, spawn x, explosion dither). On wrap it restarts at 0x10000 + (d0 & 0xfe), so the caller's d0 nudges the restart point by an even offset. Both constants are RELOCATED longwords — the raw listing shows #$7832 and #$0. The cmpi.l/blt compare is signed, and d0 is stacked across the wrap and restored, so callers keep it.
cmt 0x102fe make_fill_pattern(d0.b = colour): builds the 4-plane fill longwords d1:d2 tested by fill_screen's move.l d1/d2 loop. DEGENERATE, AND GENUINELY SO: all four btst/or blocks (0x10302/0x1030e/0x1031a/0x10326) are byte-identical (btst #0 / or.l #$ffff0000,d1), so the last three are no-ops, d2 is cleared and never written, and only bit 0 of the colour survives — into plane 0, making it a 2-colour fill. Not a depacker artifact (token trace) and not mid-entry aliases (nothing branches to 0x1030e/0x1031a/0x10326). All three fill_screen callers pass colour 0, so the game never notices. Reproduced as-is by recreate/src/fill.c.
cmt 0x10334 fill_pattern_n: unreferenced. Fills d0 groups of 8 bytes at (a0)+ with d1/d2 — a count-driven twin of fill_screen's loop. No caller anywhere in the image.
cmt 0x135f4 select_sprite_base(a0=object, d0.w=flags): returns in d1 the rider sprite-set base — 0x1c64a for player 1, 0x1ebaa for player 2, 0x22f4a otherwise — plus 0x130 when the facing bit (15) is set. Callers store d1 into draw_src. Was mis-named stub_ret2 (Ghidra decompiles it to `return;` because the result is a register).
cmt 0x1033e count_objects_and_pad: counts live objects (live_object_count) and eggs (egg_count) when game_phase==0, or message characters (message_char_count) otherwise — then burns busy-wait loops proportional to (8 - live), (0x0e - eggs) and (0x23 - chars). The delays are a frame-time equaliser so the frame costs the same however much is on screen.
cmt 0x1052e draw_platforms: OR-blits every platform_sprites record whose platform_present byte is > 0 (then latches it to -1), after forcing the paired platform flags 2/3 and 6/7 to agree. This is the repair pass that redraws platforms sprites have overdrawn. Was mis-named anim_sprites.
cmt 0x1757a raise_floor: every 7 frames (while the counter at 0x10d65 is non-zero) playfield_bottom moves up one 0xa0-byte row and paint_floor_row paints the two halves of the newly exposed row. wave_manager adds 5 rows per wave for waves 0-3, so the floor/lava builds up over the opening waves; any object whose draw address reaches playfield_bottom is flagged 0x100 and dies. Was mis-named scroll_screen_up.
cmt 0x175ba paint_floor_row(a1 = row): for 5 groups of 4 plane words, sets plane 3 wherever all four planes are 0 — i.e. recolours background pixels to colour 8 without touching existing graphics. Was mis-named clear_sprite_mask.
cmt 0x17438 dissolve_platforms: for each effect_table record, looks up platform_sprites[kind] (0x119c8 + kind*0x10), un-draws the platform bitmap a row at a time and ORs random noise sampled through rng_ptr over it. wave_manager fills effect_table from (old layout mask AND NOT new), so this animates the platforms that vanish between waves. Was mis-named draw_explosions.
cmt 0x175de animate_ground_shrink: gated on the counter at 0x10d68 (set for waves 3-4). Walks a 0x10d68..0x10d9e state block, blits two sprites (0x18636 / 0x187e6) with blit_sprite_mask+blit_sprite, and on wave 3 steps ground_x0 up and ground_x1 down — platform 0 (the ground) narrows. STILL # ctx: the retracting-ground reading is inferred from the x-range shrink; rendering the two sprites at 0x18636/0x187e6 with tools/extract_graphics.py would settle what is actually drawn. Was mis-named draw_scroller.
cmt 0x182a2 pos_to_screen(x@10.w, y@12.w -> dst@4.l, shift@8.w): dst = screen_base + y*0xa0 + (x/16)*8, shift = x mod 16. Callers push y, x, then a word and a long of space, and pop the results into draw_dst / draw_shift. Both offsets are folded in with adda.w, i.e. only the low word of each product, SIGN-EXTENDED — so from y=205 on (y*0xa0 > 0x7fff) the address runs backwards. Off-screen only, but the reconstruction matches it.
cmt 0x182d6 screen_to_pos(dst@4.l, shift@8.w -> x@10.w, y@12.w): the inverse of pos_to_screen — divides (dst - screen_base) by 0xa0 for y and by 8 for the word-group. Unreferenced anywhere in the image (dead code), and its x reconstruction multiplies the group by 22 rather than 16, so it would not round-trip. Was mis-named pos_to_screen2.
cmt 0x144b0 flash_hiscore_color: bumps a counter and XBIOS Setcolor(10, 0x400 | (n & 7)) — pen 10 flashes through 8 shades. Its only caller is the high-score entry wait loop.
cmt 0x144d4 hiscore_key_input: Bconstat/Bconin for the name entry — backspace moves the cursor left, RETURN finishes (jumping back into _start at 0x10006), space and A-Z (lower case folded up) store into draw_dst_off, redraw via draw_hiscore_entry and advance draw_shift (the cursor index, capped at 15). Was mis-named read_key.
cmt 0x14538 hiscore_joystick_input: same IKBD interrogate as read_joysticks, picks the stick belonging to the entering player (draw_src == player2), fire finishes the entry, up/down step the current letter through ' ' and 'A'..'Z' with wrap, left/right move the cursor; 0x1415e is the auto-repeat delay. Was mis-named vsync_wait2.
cmt 0x1437a check_highscore: runs only when game_over_flag is set. Picks the higher of the two players' score strings, and if it beats hiscore_name it marks hiscore_dirty, copies the score, clears the screen, and enters the name-entry loop (hiscore_key_input / hiscore_joystick_input / flash_hiscore_color) which never returns — RETURN or fire restarts the game.
cmt 0x146a6 draw_hiscore_entry: stores draw_dst_off (the current letter) into hiscore_name[draw_shift], sets text_shift 1 or 9 for the odd/even column, points text_ptr at screen_base+0x52b0 + cursor*4 and draws the single character.
cmt 0x14658 draw_hiscore_cursor: paints the 0xfefefefe underline row at screen_base+0x57b0 and then the wide cursor bar at the column given by draw_shift.
cmt 0x14160 score_update(a0=object) / 0x14166 score_update_p2 / 0x14172 score_update_p1: these do NOT take an amount — callers add directly into the ASCII score digits at object+0x41..+0x43, and this propagates the decimal carries up the string, awards an extra life (and draw_lives + play_sound) each time the 10000s digit turns even, then redraws the score. Was mis-named add_score*.
cmt 0x14246 draw_lives(a0=object): dispatches to draw_lives_p1/draw_lives_p2 by comparing a0 with player2, then draws five life glyphs (0x1861d / 0x18629) or blanks (0x1861b) from object+0x4c. Was mis-named bonus_life.
cmt 0x1435c find_free_message: returns in a0 the first message_table slot whose kind byte is 0 (the caller fills in string/timer/colour/position). It tests nothing else. Was mis-named check_messages.
cmt 0x12606 update_eggs: walks object_table and drives each object's egg sub-record (+0x1e state). States seen: 0x24 falling into the lava, 0x22 resting on a platform, 0x21 ready to hatch, 0x23 thrown, 0x20/0x19 the rider death animation, 0x12/0x11.. the hatch countdown, >0x20 in flight (update_egg_physics + gravity). Hatching turns the egg back into a rider with the buzzard sprite sets 0x18b9a/0x18aea/0x18c4a. Was mis-named animate_objects.
cmt 0x1285c update_egg_draw: the draw/advance tail of update_eggs, entered by jumps — erase_egg_sprite / draw_egg_sprite and then the next object. Ghidra split it into its own function because the loop jumps back here. Was mis-named draw_objects_buf2.
cmt 0x12914 draw_egg_sprite: ORs the egg sprite (draw_src, 4 words x draw_rows, stride 0x4d words) at draw_dst with draw_shift, plus the wrap-around column pass; if the destination reaches playfield_bottom the egg state becomes 0x24 (fell in the lava). Was mis-named draw_sprite_at.
cmt 0x129b4 erase_egg_sprite(a0=object): AND-NOTs the egg sprite recorded at object+0x2a/+0x2e/+0x32/+0x33 out of the screen, including the wrap-around column. It allocates nothing. Was mis-named alloc_object.
cmt 0x12a2a update_egg_physics(a0=object): tests the egg's box against platform_table (landing: state 0x22, egg sprite 0x1899a, roll direction from platform_edge_table) and then against platform_sprites; sets the roll/bounce sprites 0x18a0a / 0x18a7a and, once the egg has settled and stopped rolling, state 0x21 = ready to hatch. Was mis-named advance_anim.
cmt 0x12caa render_objects: entry — a0 = object_table, falls into render_object_body.
cmt 0x12cb2 render_objects_next: the loop tail (a0 += 0x4e, stop at effect_table). Not a callable routine — it is only ever branched to. Was mis-named render_objects_b.
cmt 0x12cc2 render_object_body: per-object physics + draw. Branches on the flags word: bit14 platform-edge bump, bit8 falling into the lava (death + score), bit7 respawn via spawn_points, bit9 walking on a platform, otherwise flight with gravity; then selects the rider sprite set (0x1a80a/0x1cd6a for the players, 0x1f2ca/0x201ea/0x2110a by enemy type, 0x2202a when dead) and erases + redraws through draw_object_mask/draw_object_data. Was named render_objects_impl.
cmt 0x13300 check_platform(a0=object, d0=flags): scans platform_table for a present platform containing (object x, y); on a hit it snaps y to the platform top and returns d0 | 0x200 (standing), otherwise it clears bit 9 and resets the walk state.
cmt 0x13628 draw_spawn_sparkle(a0=object, d0=flags): indexes the spawn point recorded in object+8 (offset into spawn_points), takes a 3-longword pattern from 0x1194c and a plane-select byte from 0x11944, and calls blit_pattern_rows three times — the effect drawn while a rider materialises. STILL # ctx: the "sparkle" reading is from the call site (bit7 respawn branch); rendering 0x1194c would confirm the shape. Was mis-named blit_sprite3.
cmt 0x1369c blit_pattern_rows(a3=dst, d2=plane select, d5/d6/d7=row data): for each of 4 plane words, ORs the data in where the d2 bit is set and AND-NOTs it out where it is clear, on three rows at strides 0 / 0xa0 / 0x140.
cmt 0x13842 collision_check: per object, box+pixel tests (test_overlap) against platform_sprites, then the other objects (joust: the higher rider wins — start_death_anim for the loser, score for the winner, joust_bounce otherwise), then the eggs held by other object slots (the 250/500/750/1000 chain from egg_bonus_table), then pterodactyl_table.
cmt 0x13ef2 test_overlap: broad phase for two boxes staged in hit_box_a/hit_box_b {dst.l, src.l, cols.w, shift.b, rows.b, cur col.w, y.w}; if their y bands overlap it aligns both to the same column and calls pixel_collision for the overlapping rows, setting collision_hit.
cmt 0x13fe6 pixel_collision: ORs the four plane words of each sprite row (plus the wrapped word when a shift is in play), shifts both to a common origin, and sets collision_hit = 0xff on the first row where the two masks share a bit.
