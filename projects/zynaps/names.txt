# ZYNAPS (Atari ST, Hewson Consultants 1988; coder "HOWIE", graphics Pete Lyon,
# music/sfx J. Dave Rogers; ST conversion credited in-game to MICROWISH).
# Binary: ZYNAPS17.PRG - plain 68000 GEMDOS PRG, text 0x10000..0x19f46 at Ghidra load
# base 0x10000, no data segment, bss to 0x6e96e. Ghidra address = image offset + 0x10000.
#
# Sections below: entry+interrupts, front end, frame loop, entities, weapons, enemies,
# mothership, collision, scroll/tiles, sprites/blit, HUD, text/score/high score, sound,
# IKBD/file I/O, tables and globals.
#
# A trailing '# ctx' marks a name inferred from call context rather than a confirmed
# body read (ApplyNames strips everything from the first '#'). Where two independent
# readings disagreed the alternatives are kept in that tag.
#
# Verified facts worth keeping at the top:
#  - The only OS calls are GEMDOS Super(0x20), Fopen/Fread/Fclose and one Line-A $a00a
#    (hide mouse) at 0x10010. XBIOS Xbtimer at 0x16abe is inside dead code (0x16aa6).
#    No FDC/DMA access, no protection check anywhere in the PRG.
#  - Screen buffers are hard-coded absolute RAM at 0x70300 / 0x78000 (needs 512 KB);
#    nothing is Malloc'd and the basepage is never shrunk.
#  - Interrupts: VBL $70, MFP Timer B $120 (raster palette split), MFP ACIA $118 (IKBD).
#  - Self-modifying data: per-section filenames are patched in place in the text segment
#    (see the cmts on 0x196b5 / 0x196ab / 0x196ee / 0x19714 / 0x197e5).
